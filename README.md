# DILL

**Disentangling Spurious Correlations in Vision-Language-Action Models via Predicting Domain-Invariant Latent Lookahead**  
**CoRL 2026**

[Project Page](https://dill-vla.github.io/) · [Paper](https://arxiv.org/abs/2609.37165) · [Dataset](https://huggingface.co/datasets/DILL-VLA/DILL-Dataset) · [Models](https://huggingface.co/DILL-VLA/DILL)

DILL trains vision-language-action models to predict task-relevant future representations while suppressing task-irrelevant visual cues. It reduces shortcut learning and improves robustness to changes in viewpoint, background, lighting, and noise.
